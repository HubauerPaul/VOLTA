Byte notation: `const XX` = never changes, `a..b (n)` = range and number of distinct values, `CRC` / `counter` = E2E protection (see docs/can-bus.md); E2E `unsolved` = byte 0 is a CRC and byte 1 a counter, but the CRC scheme is not known yet. Leads = bytes or 16-bit words whose value follows the throttle pedal or the motor speed during the sweep (|r| ≥ 0.8); a lead is a hint, not a decoding.
